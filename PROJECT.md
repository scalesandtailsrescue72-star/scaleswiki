# ScalesWiki Project Plan

## Overview
ScalesWiki is a modern reptile care website focused on education, printable resources, and rescue-backed content.

## Goals
- Build a polished landing page for reptile care content.
- Provide species and shop sections for discovery.
- Organize content with reusable components and simple data files.

## Current Structure
- app/: application routes and global styling
- components/: reusable UI sections
- data/: content data for species, guides, and academy lessons
- public/: static assets such as logos and images

## Next Steps
- Add detailed species detail pages.
- Expand guide and shop product content.
- Improve SEO metadata and accessibility.
