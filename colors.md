# ScalesWiki Color Palette

## Primary Palette
- Background: #08120D
- Card: #122018
- Primary Green: #2ECC71
- Accent Gold: #C9A227
- Text: #F5F5F5
- Muted: #9CA3AF

## Usage Notes
- Use the green for primary actions and highlights.
- Use the gold for accents, badges, and emphasis.
- Use the dark background and card tones for depth and contrast.
- Keep text in the light neutral for readability.
